# 🐍 Snake Game

A classic Snake game written in Python using Pygame, inspired by the Snake game on old mobile phones. Control the snake, eat food, grow longer, and try to get the highest score without hitting the walls or your own tail.

This project was created for practice and fun. I plan to improve it and add new features over time.

## 🎮 How to Play

- Use the arrow keys to control the snake.
- Eat food to grow longer and earn points.
- Avoid hitting the walls or the snake’s own body.
- The longer the snake gets, the higher your score.

## ✨ Features

- Classic Snake gameplay
- Keyboard controls
- Score counter
- Snake grows after eating food
- Simple and clean graphics
- Easy to extend with new features
